# Codex build evidence

The education feature is wired into the existing application, not a separate demonstration screen.

- src/main.ts mounts the education panel, refreshes real local metrics, and attaches the learning editor to each story's detail view.
- src/learning-ui.ts implements the editable lesson form, explicit classroom-permission flow, offline handout export and in-app Codex artifact browser. Public project documentation is bundled for offline access. The engineering handoff exports repository context without reading private story data.
- src/types.ts defines optional LearningCard metadata so existing saved stories remain readable without a database migration.
- src/agents/learning.ts lives in the folklore-agent domain. It validates teacher-authored learning content, calculates real device-local activity counts and exports credited handouts while enforcing separate classroom permission. It never invents a proverb or automated cultural interpretation.
- src/storage.ts merges editable metadata in one IndexedDB transaction. Notes and lesson edits preserve one another and keep original audio bytes and hashes intact.
- tests/learning.test.ts covers meaningful metrics, export permission, native text/attribution and invalid inputs. tests/browser.mjs exercises the product workflow, including concurrent notes/lesson saves, offline persistence, permission and unsaved-edit gates, export and the Codex handoff's privacy boundary.

Codex performed repository planning, implementation, review and documentation. The work uses AGENTS.md, the oral-story pipeline skill and the reusable pamchenga-development lifecycle skill. No special UI plan mode, parallel agents or live in-browser Codex connection is claimed. audio-storage-mcp and c2pa-signer-mcp are unavailable in this session; browser IndexedDB is the storage fallback and C2PA remains unsigned.

## Whisper integration

The folklore-agent domain now includes a genuine faster-whisper backend for OpenAI Large V3 and Turbo. `src/whisper-ui.ts` handles model/language selection, separate upload permission and reviewed-draft use. IndexedDB version 2 adds a durable `transcriptions` queue while retaining existing stories/lesson data. `public/sw.js` is the only remote-request path, polling accepted jobs and validating their model/hash/result before atomically storing the generated draft separately from notes. `public/whisper-result.js` validates timestamp and result structure. `opening-agent` tags first-30-second ritual text cues using returned segments.

`server/app.py` persists jobs in SQLite, verifies audio hashes, runs full-audio transcription with VAD disabled, recovers interrupted jobs and deletes temporary audio after processing. `server/download_model.py` explicitly prepares weights; no model download happens silently at browser startup. `vite.config.ts` proxies the development API. See server/README.md for the single-operator deployment boundary and model-host access blocker. Actual checkpoint inference has not been verified in this cloud environment.

## Netlify + hosted Whisper deployment

`netlify/functions/transcribe.ts` and `netlify/lib/hosted-whisper.ts` implement the selected public-site gateway as part of the folklore-agent domain. The provider key is read only from function runtime secrets; the shared pilot access code gates provider usage. `src/transcription-config.ts` selects hosted mode through the public non-secret build flag and the 4 MiB upload cap. The worker detects the service before uploading, blocks old jobs on a provider change, keeps access codes in memory only, pauses/resumes authorization failures and stores synchronous hosted results locally. Invalid provider text/timestamps fail without automatic paid retries. The browser shows explicit Groq consent and never crops audio to meet the host limit.

`tsconfig.functions.json` extends strict TypeScript checks to the function code. Hosted unit tests and `tests/netlify-browser.mts` cover the new boundary using mocked Groq responses. `netlify/README.md` contains the exact two required runtime variables and deployment steps; they are not available to the agent. No live Groq request or completed Netlify deployment is claimed before that account configuration is verified. `deploy/Dockerfile.whisper` packages the optional Python backend with a compatible decoder and passed a local build/non-root runtime smoke check. It has not been published as a public service.

## Storyteller benefits implementation — 10 November 2026

Consent v2, migration, agreement checks and license/withdrawal text live in `src/consent.ts`; `src/consent-ui.ts` attaches form-scoped notices. `src/story-exports.ts` uses fflate for a return-only ZIP with unchanged original bytes and unsigned passport, and retains the sharing gate for third-party audio and passport exports. Main UI handlers re-read persisted consent for third-party exports. `src/storage.ts` appends consent snapshots and own-copy request notes atomically, preserving concurrent metadata. Denied backup permission removes pending backup jobs atomically, and the worker rechecks current authorization before an upload attempt. Passport fields remain unsigned/self-reported. Fake IndexedDB is a unit-test dependency, not a browser storage replacement; the PWA still uses real browser IndexedDB. The existing Whisper configuration uses optional access to Vite's environment so storage can also be imported in the Node tests; provider selection and upload limits in browser builds stay the same. The service-worker cache is refreshed for the updated build; tests still derive its name from the controlling worker's served source. No backend, payment service or legal verification is added.
